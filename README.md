# strmcrown.dev

Личный сайт-визитка. Собран на [Hugo](https://gohugo.io/), без темы и без
внешних зависимостей: шрифты системные, иконок и CDN нет.

## Разделы

- **Наука** — публикации и исследовательские проекты
- **Программы** — открытые проекты и инструменты
- **Учёба** — курсы и материалы
- **Чтение** — книги и отзывы
- **Конкурсы** — хакатоны и соревнования
- **О сайте** — контакты

## Локальный запуск

```sh
hugo server -D      # http://localhost:1313
hugo --gc --minify  # сборка в ./public
```

Версия Hugo зафиксирована в `.github/workflows/hugo.yml` (0.164.0).
Деплой на GitHub Pages происходит автоматически при пуше в `main`.

## Оформление

Вся вёрстка — в `static/css/style.css`. Палитра задаётся CSS-переменными в
начале файла: пергамент и медная патина в светлой теме, тёплый чёрный и
янтарь в тёмной. Структуру держит моноширинный шрифт (навигация, даты,
подписи), текст набран антиквой.

Тёмная тема следует системной настройке; кнопка `◐` в шапке переключает её
вручную и запоминает выбор в `localStorage`.
